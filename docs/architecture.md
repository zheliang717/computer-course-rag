# 项目设计与架构

智学助手面向计算机课程的学习和教学，以课程分配用户与资料。学生、教师和管理员使用同一网页应用，通过服务端权限进入不同工作区。

## 业务模块

1. 课程：概览、教师、目标、考核、大纲、章节、知识点和阅读范围；草稿、预览和确认发布。
2. 资料：文字 PDF 与文字页导入、异步解析、分块、向量化、取消/重试、版本查看与恢复。
3. AI：角色及页面上下文、课程优先/严格 RAG/通用模式、流式状态、停止/重试、会话、引用定位和反馈。
4. 题目与作业：手动录题、教师私有 PDF 原题选编、AI 草稿与审核、组卷、发布、提交、批改和版本快照。
5. 学习：题库练习、错题待巩固/已巩固、复习推荐、学习计划、笔记、成绩与反馈。
6. 教学分析：学生作答、课程整体成绩与薄弱知识点、AI 讲评及效果回看；最终评分由教师确认。
7. 排课：学期、课次、教室、可用时段；候选与影响预览、管理员确认、教师调课申请与审批。
8. 管理：注册、邀请、身份申请、账号协助、模型与配额、设备会话、评测和审计导出。

## 运行结构

Vue 网页 → 同站点 Web 代理 → FastAPI → PostgreSQL/pgvector。资料按页解析并建立带来源的片段；问题先经过身份、课程与资料权限过滤，再进行混合检索和生成。模型凭据由管理员维护，按资料批准范围提供检索片段。

数据库保存业务记录、资料正文/向量与任务状态；模型缓存保存在宿主机目录；已保存在线模型凭据的加密密钥使用独立持久卷。恢复系统时这些资源需配对。

教师及管理员确认授课课次，学生实际提交作业形成章节作业进度。学生不能直接把课程标成完成。教师可申请调课，管理员审批后才修改；教师、学生或教室时间冲突不允许豁免。

AI 生成建议先进入可核对的结果或草稿，发布、最终评分和课表变更继续由有权用户确认。工程回归、检索证据精度与教学语义正确性分别验收。
