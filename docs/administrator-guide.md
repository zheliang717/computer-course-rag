# 管理员使用手册

1. 管理用户、注册策略、邀请、教师申请及账号协助；维护课程并分配教师与学生。
2. 管理资料库、处理任务与版本。资料发布和允许模型使用检索片段分开核对；恢复内容需重新核准相关范围。
3. 配置兼容模型的服务地址、模型标识、Key、超时和检索参数，确认连接与配额。已保存配置优先于环境默认值。
4. 管理学期、教室、可用时段和课次；预览候选方案、审批调课，并核对变更影响。
5. 在质量评测发起离线检索任务，查看、比较和导出结果；工程指标与教学效果分开判断。
6. 使用管理助手准备操作与查看依据，涉及更改时仍须经过预览/确认流程；可筛选日志并导出课程成绩和学情。
7. 按部署手册保管数据库、配对密钥和模型缓存。源码克隆不包含个人部署的数据与凭据。
