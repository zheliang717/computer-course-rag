# Windows 简便迁移

适用于当前 Windows x64 主机与 Docker Linux 容器，迁往另一台 Windows x64 电脑。运行迁移包不要求安装 Python、Node.js 或 Git；新电脑需要先安装并启动 Docker Desktop。

## 旧电脑：双击导出

1. 保持 Docker Desktop 和现有系统运行。
2. 在项目根目录双击 `Export.cmd`。
3. 等待导出完成，打开项目目录旁的 `zhixue-migration-packages/zhixue-日期时间-编号/` 文件夹。
4. 把这个**完整文件夹**复制到移动硬盘或新电脑。

导出内容包括当前运行镜像、两套数据库（若已部署公网副本）、各自的模型配置密钥、程序源码、环境配置、当前使用的模型缓存，以及文件校验值。开发依赖、历史修改副本、历史日志、旧备份及未使用的模型不重复打包。模型缓存中的文件链接整理为独立文件，避免携带两份相同权重。数据库采用一致性快照导出，导出过程不停止原系统。

运行镜像默认压缩成 `images.tar.gz`，并在删除临时未压缩镜像归档前核对解压后完整 SHA-256。新导入器同时兼容以前的 `images.tar` 包，不需要手动解压镜像文件。迁移包目录仍须完整复制。

模型密钥按各套系统实际状态登记：已保存加密凭据时必须携带原配对密钥；仅从 `.env` 读取凭据且未生成密钥时，保留对应配置，不会凭空生成密钥。加密凭据确实存在但密钥丢失时仍会停止导出。

迁移包包含账号数据和密钥，默认放在 Git 仓库外；不要把迁移包传到代码仓库。需要改变导出位置时，可执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\portable.ps1 -Action Export -ExportDirectory 'D:\智学助手迁移包'`，目标必须在项目目录外。

## 新电脑：双击导入

1. 安装并启动 Docker Desktop，使用 Linux 容器。
2. 将整个迁移包放到准备长期保留的位置，双击包根目录的 `Import.cmd`。
3. 等待镜像、数据库及配置恢复完成；系统就绪后会打开页面。

本机系统入口为 `http://127.0.0.1:5173/`，公网副本在该电脑的入口为 `http://127.0.0.1:18080/`。原有账号密码与模型配置沿用备份时的状态。

包内的 `project/` 是恢复后实际运行的程序和配置目录，导入完成后仍需保留整个目录。日常查看、启停本机系统时，在该目录执行 `docker compose -p computer-course-rag ps`、`stop` 或 `start`，避免目录名改变后误建另一套空数据库。迁移包不含 `.git`，后续开发可另行克隆仓库。

导入前会校验文件，并检查已有容器、数据卷和端口；发现已有安装时停止，防止覆盖数据。失败时保留现场，不会自动删除数据库或强制重试恢复。请保留窗口中的错误信息交给维护者排查。

## 公网网址与日常使用

新电脑的公网访问需要另外安装、登录 Tailscale 并启用 Funnel。按[部署手册的跨设备访问步骤](deployment-guide.md#7-让其他设备访问)恢复入口；已有迁移包包含运行镜像，不需要重新初始化副本或执行历史镜像构建。新设备的网址需重新核对。

从 GitHub 克隆得到的是源码、公开资料及部署文件，不含现用数据库、私有模型密钥或模型缓存。完整换电脑时使用上述迁移包；只想开发代码时按[部署手册](deployment-guide.md)安装开发环境。

迁移包是导出时的快照，两台电脑之后的数据不自动同步。正式切换时，先停止旧系统的新写入，再做最终导出；核对新电脑的登录、资料、作业成绩和 AI 功能后，再停用旧入口。浏览器中尚未提交的草稿不在数据库迁移范围内。
