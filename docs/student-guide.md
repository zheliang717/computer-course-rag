# 学生使用手册

1. 登录后，首页查看各课程的学习进度、待办作业和课表。首次账号可由管理员创建或按注册/邀请规则加入。
2. 在课程详情查看教师、课次、大纲、知识点和阅读资料，点击资料可阅读并定位到相应页。
3. AI 助手默认课程优先。选定课程并提问，查看讲解、引用和补充知识；等待时可观察阶段状态，必要时停止或重试。
4. 练习中心点击题目作答，提交后查看反馈和解析。错题以实际再练结果更新待巩固/已巩固状态，历史记录保留。
5. 在“我的作业”打开作业完成逐题回答并提交，查看提交状态、成绩和教师评语。是否允许 AI 辅导按教师设置执行。
6. 可管理学习笔记与计划；个人中心支持头像、姓名、密码、课程邀请和设备会话。

课程授课进度由教师或管理员确认的课次形成；学生实际提交影响章节作业进度。公开示例数据用于演示，不是正式教学记录。
