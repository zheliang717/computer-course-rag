# 教师使用手册

1. 在所授课程编辑概览、目标、考核方式、大纲、知识点和对应阅读，保存草稿，预览确认后发布。
2. 上传有权使用的课程资料，关注处理状态；教师私有出题 PDF 与学生 RAG 资料分开管理。
3. 在资料选题工作间选页、查看原文并选编题目，核对来源、答案、分值和重复提示；AI 新题与原文选题分别保留依据，审核后入库。
4. 创建作业草稿，调整题目顺序、分值、截止时间和 AI 辅助规则，预览后发布。修订使用独立版本，既有提交与成绩保留。
5. 查看学生名单、逐题回答和评分；AI 可准备评语、讲评、个人作答分析及课程整体学情，教师核对后决定采纳与最终评分。
6. 使用教学计划、备课和复习建议；管理课程公告、成员及邀请。
7. 调课通过申请和审批流程完成。教师不能直接修改课表，AI 也不会代为绕过审批。
