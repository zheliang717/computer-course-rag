# 智学助手

面向计算机课程的 AI 辅助教学与学习平台，以课程为核心，将知识库、智能问答、练习作业、教学分析和课表管理整合在同一系统中。

平台提供学生、教师和管理员三个角色的工作区。内嵌 AI 助手结合用户身份、当前课程与页面内容，帮助学生理解知识、帮助教师准备教学、帮助管理员处理日常事务。支持电脑、平板和手机浏览器访问。

## 系统特色

- **随处可用的 AI 助手**：既有独立问答工作区，也有页面内的悬浮入口，可围绕当前课程、题目、作业或管理任务继续交流。
- **有资料依据的知识讲解**：通过 RAG 检索课程资料，由模型组织讲解，并提供资料名称、页码和原文定位，便于核对与继续阅读。
- **贯通教学与学习**：覆盖课程建设、资料维护、出题组卷、作业批改、错题复习和学情分析，使教学内容与学习反馈相互衔接。
- **分角色的功能与权限**：学生专注学习，教师负责授课与评价，管理员维护平台和教学安排；服务端按身份及课程关系控制访问。
- **适合持续使用的交互**：支持流式回答、等待提示、公式与代码排版、历史会话、条件查询与分页，以及适配不同屏幕的布局。

## 角色与功能

### 学生端

- **学习首页**：按课程查看学习进度、作业完成情况、课程表和学习计划，快速进入待办事项及 AI 问答。
- **课程学习**：查看课程概览、教师信息、授课时间与地点、课程大纲、章节知识点和对应资料。
- **知识问答**：结合课程资料获取分步讲解，通过引用回到原文，也可围绕当前题目追问知识点与解题思路。
- **练习中心**：选择题目进行作答，查看反馈与解析；使用错题再练、巩固记录和复习推荐持续练习。
- **作业与成绩**：查看作业要求、完成并提交答案，回看提交记录、教师评语和成绩反馈。AI 辅助范围遵循教师设置。
- **个人学习管理**：维护笔记与学习计划，管理头像、个人资料、密码和登录设备，选择七天免登录。

### 教师端

- **课程建设**：创建并持续维护课程概览、学习目标、考核方式、大纲、章节、知识点和阅读范围，支持草稿、预览与确认发布。
- **资料管理**：上传课程 PDF、关联资料库，查看处理状态和资料版本，维护学生可见的学习内容。
- **题库与组卷**：手动录入题目、从教师私有 PDF 中选编原题，或通过 AI 生成题目草稿；审核后入库，调整试卷顺序与分值。
- **作业与批改**：发布作业、查看学生姓名及作答内容、评分并提供反馈，利用 AI 准备讲评和评语建议。
- **学情分析**：查看学生个人与课程学生整体的成绩分布、作答表现及薄弱知识点，结合 AI 分析调整教学重点。
- **教学安排**：查看课表、确认授课课次、发布课程公告；需要变更课表时提交调课申请，由管理员审批。

### 管理员端

- **账号管理**：管理学生、教师与管理员账号，配置注册规则、邀请和身份审批，处理账号协助及登录会话。
- **课程与资源管理**：维护课程、成员关系、资料库和公告，统一管理教学内容与访问范围。
- **排课与调课**：维护学期、教室、课次和可用时段，生成并预览排课候选，审批教师调课申请。
- **模型与检索配置**：管理 AI 服务、模型名称、调用凭据、额度和检索参数，检查模型连接与运行状态。
- **平台维护**：查看资料处理任务、评测结果及运行日志，使用数据导出等工具辅助管理。
- **管理 AI 助手**：围绕管理数据、资料处理和排课需求获取建议，预览相关操作后再确认执行。

## 内嵌 AI 助手

### 根据角色提供帮助

学生端侧重知识讲解、解题辅导、复习推荐和学习计划；教师端侧重备课、出题、审题、讲评及学情分析；管理员端侧重平台管理、资料处理和辅助排课。

助手可使用当前页面的相关业务上下文，减少反复描述问题的操作。生成的课程内容、题目、评语或排课建议通过草稿和预览供用户核对，发布内容、确定成绩和修改课表仍由有权限的用户确认。

### 三种回答模式

- **课程优先**：学生和教师的默认模式。优先检索课程资料，再由 AI 结合证据讲解；资料不足时可补充通用知识，并区分来源。
- **严格课程 RAG**：回答以课程资料为依据，检索证据不足时明确说明。
- **通用助手**：用于一般知识问答与任务协助，不要求命中课程资料。

回答支持 Markdown、数学公式、代码块和引用定位，提供流式输出、等待提示、停止生成、重试、历史会话与反馈。系统支持兼容 OpenAI Chat Completions 的模型服务，可由管理员配置服务地址、模型及凭据。

## RAG 课程知识库

课程知识库由教师或管理员导入资料后建立。系统对文字型 PDF 或文字选读进行分页解析、分块与索引，保留资料标题、页码和片段之间的关联；资料支持处理进度、取消、失败重试、历史版本查看与恢复。

提问时，系统先按用户身份和课程权限确定可访问的资料，再结合语义向量与关键词检索相关片段，交给 AI 组织回答。用户可从回答中的引用查看原文，使讲解与课程内容对应。在线模型使用资料时遵循资料配置的使用范围。

学生学习资料与教师私有出题资料分别管理。教师从 PDF 中选编原题时保留来源页与原文，审核后再形成题库内容，避免将未发布的试题直接提供给学生检索。

## 教学流程

- **课程建设与发布**：维护概览、大纲、章节和知识点，关联资料与阅读范围，预览后发布；后续可继续编辑完善。
- **出题、作业与评价**：题目经教师审核入库，组卷发布后由学生提交，教师批改并反馈，相关记录用于教学分析。
- **练习与复习推荐**：根据错题巩固情况、复习时间、薄弱知识点和已授课内容推荐练习，同时保留作答与巩固记录。
- **进度与课表联动**：课程授课进度按已确认的课次计算，章节作业进度随实际提交更新；学生可查看进度和对应详情。
- **辅助排课与审批**：AI 帮助整理排课需求，程序生成候选并检查教师、学生及教室冲突，管理员预览确认；教师通过申请调课调整安排。

## 技术栈

- **前端**：Vue 3、TypeScript、Vite，使用 Markdown 与 KaTeX 渲染回答。
- **后端**：Python 3.12、FastAPI、SQLAlchemy、Alembic。
- **数据库与检索**：PostgreSQL 16、pgvector、Sentence Transformers，支持向量与关键词混合检索。
- **资料处理与部署**：PyMuPDF、持久化后台任务、Docker Compose；使用 pytest、Playwright 和 GitHub Actions 进行工程检查。

## 快速部署

准备 Git、Node.js 22 和 Docker Desktop，启动 Docker 并使用 Linux 容器。以下命令适用于 Windows PowerShell：

```powershell
git clone https://github.com/zheliang717/computer-course-rag.git
cd computer-course-rag
Copy-Item .env.example .env
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
```

将 `.env` 中的 `AUTH_SECRET` 改为自定义随机字符串，然后启动：

```powershell
docker compose -p computer-course-rag up --build -d
```

打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。首次初始化的管理员账号为 `admin`，初始密码为 `admin123`，登录后请修改密码。

默认配置用于本地体验，使用离线回答与基础检索。启用在线 AI 讲解和语义检索时，需配置模型服务并准备向量模型；创建课程、关联资料库并上传资料后，可建立自己的课程知识库。详细配置见[部署手册](docs/deployment-guide.md)。
