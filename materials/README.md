# 资料与原创演示

公开源码仅附项目自行编写的三页演示 PDF、来源索引、固定评测问题和选读范围登记；不附第三方教材 PDF、网页原文或下载的模型权重。

`test-data/computer-course-rag-test-data.pdf` 可供新系统上传测试，主题为栈与队列、二叉搜索树和排序。其源码是 `scripts/build_test_pdf.py`，只依赖项目现有 PyMuPDF，可自行重建；文本与示例均为本项目原创测试夹具。

第三方资料索引见 `sources.json`，中文选读范围见 `flagship-readings.json`。标题、作者、链接和哈希用于追溯，不代表项目替资料权利人授予使用或再分发许可。使用者应自行取得适当材料并保留具体版本的署名和许可。

管理员建立资料库并绑定课程，上传资料、等待处理、发布并核准在线片段使用。文件出现在磁盘目录中不等于已经入库，模型配置成功也不等于所有材料都获准外发。

`eval/` 提供项目编写的开发样题与检索定位标签；正式来源题集只有在相应资料已取得并导入时才有意义。样题不作为教学正确性或生产容量证明。测试中的合成用户及成绩不代表真实教学活动。
